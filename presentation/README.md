# Presentation: "How Do You Respond?"

`deck.html` is a self-contained slide deck for a talk of 15–20 minutes about how this archive was built with Claude. It covers Geert's story, the documents, and what the project says about the rigid frameworks we work inside.

Open it in a browser. The arrow keys move between slides, `s` opens a synced speaker view with notes and a timer, and `n` shows the notes in the window.

The talk opens without an introduction: everyone is handed a paper copy of [the police memo](../drive/1J_ofXSh0r_arrestInstructions.jpg) while the first slide stays black.

Every fact in the deck comes from `index.html`. Photo credits are on the slides.
